# ИзносТест: установка на разные платформы

Это PWA: обычный сайт, который ставится как приложение. Все расчёты работают без сервера и офлайн.

## 1. Выложить сайт
Нужна любая статическая площадка с HTTPS. Загрузите содержимое папки (index.html, manifest.webmanifest, sw.js, icons/):
- Netlify: перетащите папку на app.netlify.com/drop
- GitHub Pages или Cloudflare Pages: загрузите файлы в репозиторий
- Vercel: `vercel --prod` в папке

## 2. Установить как приложение
- Android (Chrome): кнопка «Установить приложение» внизу страницы или меню ⋮ → «Установить приложение»
- iPhone и iPad (Safari): «Поделиться» → «На экран Домой»
- Windows, macOS, Linux (Chrome, Edge): значок установки в адресной строке

## 3. Включить распознавание по фото (необязательно)
Сканер бирки и обуви использует Claude API. Ключ нельзя хранить в браузере, поэтому нужен маленький сервер:
1. Положите `server/api/scan.js` в проект на Vercel (или перенесите функцию на Netlify/Cloudflare Workers).
2. В настройках проекта задайте `ANTHROPIC_API_KEY`, а также `ALLOWED_ORIGIN` (адрес вашего сайта). Модель можно сменить переменной `MODEL`.
3. Впишите адрес функции в начале `index.html`, в строку с `window.SCAN_ENDPOINT`: `window.SCAN_ENDPOINT = "https://ваш-проект.vercel.app/api/scan";`
4. Добавьте ограничение числа запросов на сервере, иначе кто угодно сможет тратить ваш лимит.

Без этого шага сканер покажет сообщение «не настроено», остальное работает.

## 4. Магазины приложений (по желанию)
- Google Play, Microsoft Store: загрузите адрес сайта на pwabuilder.com и скачайте готовый пакет.
- App Store и Google Play как нативное приложение: `npm i @capacitor/core @capacitor/cli`, затем `npx cap init`, поместите файлы сайта в папку `www`, выполните `npx cap add android` и `npx cap add ios`. Для iOS нужен Mac с Xcode и аккаунт Apple Developer.
